Overview

Cookies should serve a defined purpose.

Signaturesi may use cookies, browser storage and similar technologies to maintain secure sessions, remember selected settings, protect accounts and understand product performance.

Optional technologies should remain disabled until the user provides consent where consent is required.

Core principle Essential storage should support the service. Optional storage should remain under user control.
02
What cookies are

Cookies are small pieces of browser data.

A cookie is a small text value stored by a browser when a website is visited. Cookies can remember login state, preferences, consent choices and other limited information.

Similar technologies include local storage, session storage, device identifiers and secure authentication tokens.

Cookie

Small data stored by the browser and sent with relevant website requests.

Local storage

Browser-based storage that may remain until it is removed.

Session storage

Temporary browser storage generally removed when the tab or session ends.

Token

A limited credential used to maintain or verify authenticated access.

Analytics

Analytics should measure products without unnecessary tracking.

Signaturesi may use optional analytics to understand page performance, feature reliability and aggregate usage patterns.

Optional

Possible analytics information

  • Page visits and navigation paths.
  • Browser type and general device category.
  • Feature usage and interaction counts.
  • Page loading and performance measurements.
  • Approximate region rather than precise location.
  • Error and crash events.

Analytics should avoid collecting private NEO prompts, Bean messages, uploaded files or sensitive account content.

Production requirement Identify the actual analytics provider and obtain consent before optional analytics runs where required.

Local storage and product settings

Browser storage should not become a hidden database.

Signaturesi may use local storage for lightweight interface preferences or temporary product state.

Appropriate
  • Appearance preferences.
  • Language selection.
  • Collapsed or expanded interface state.
  • Non-sensitive draft interface state.
Avoid
  • Plain-text passwords.
  • Private service keys.
  • Full private messages or AI memory.
  • Long-lived administrative credentials.

13
Browser controls

Browsers also provide storage controls.

Most browsers allow users to view, block or delete cookies and site storage through browser settings.

  • Block cookies for all sites or selected websites.
  • Delete existing cookies and local storage.
  • Clear data when the browser closes.
  • Disable third-party cookies.
  • Use private or incognito browsing modes.

Removing essential session data may sign a user out or reset product preferences.

Some countries require prior consent before optional analytics, advertising or similar technologies are used.

Signaturesi should display a consent interface where legally required and should avoid treating silence, inactivity or continued browsing as consent where stronger consent is required.

Legal configuration required Confirm the launch markets, actual cookie categories and consent requirements before publishing.
